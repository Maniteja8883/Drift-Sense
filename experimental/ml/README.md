# Experimental ML path

The original PyTorch model, losses, and training/evaluation code are retained here as research material. They are not part of the official inference or benchmark path because the repository did not contain a trained checkpoint or a reproducible ML result at the time of the rebuild. The files may require additional integration work and `requirements-ml.txt`.

Official numbers must come from `src/drift_sense/pipeline.py` via `scripts/run_benchmark.py`.
